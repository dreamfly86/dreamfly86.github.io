## What have I done?
- Participated in lightweight model adaptation for edge deployment, including pruning, quantization, and ONNX/FP16 conversion.
- Deployed and evaluated multimodal AI modules for speech recognition, face recognition, and OCR on edge devices.
- Implemented a credibility-checking workflow integrating speech, face, and OCR verification for trusted edge-side inputs.
- Contributed to Triton-based inference service integration within a cloud–edge–device collaborative architecture. 

## Technology stack
Python / PyTorch / ONNX / Triton Inference Server / PaddlePaddle / Dash / Docker / NVIDIA Jetson / gRPC / HTTP

## Achievements
- Speech recognition: 98.60% wake-up rate, 50.483 ms latency, 94 MB model size.
- Face recognition: 99.30% accuracy, 230.48 ms latency, 91.18 MB model size.
- OCR: 95% accuracy, 0.36 s detection speed, 8.2 MB model size.
- Contributed to a deployable cloud–edge–device AI pipeline for real-world multimodal edge intelligence.
